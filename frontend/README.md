# TableFlow – Frontend (Expo)

Miejsce przygotowane pod aplikację **Expo (React Native) + Expo Router + NativeWind + Reanimated/Moti**.
Działa na iOS, Android i Web z jednej bazy kodu.

Aplikacja zostanie zainicjalizowana w osobnej fazie (`npx create-expo-app`), tak aby zachować
strictly-iterative workflow. Docelowa struktura katalogów jest opisana w [`../CLAUDE.md`](../CLAUDE.md).
